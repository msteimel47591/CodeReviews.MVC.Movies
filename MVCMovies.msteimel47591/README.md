# Movies Project

This is an MVC project that tracks movies for the c# academy roadmap. It allows users to perform CRUD operations
against movies saved in a database. One of the challenges was to track something aside from movies, so I added
the ability to track television series as well.

## Requirements

* This is an application to manage information about movies.

* Users should be able to Add, Delete, Update and Read from a database, using website as the front-end.

* You need to use Entity Framework, raw SQL isn't allowed.

* There needs to be a search functionality where I can search movies by name.

* You should use SQL Server, not SQLite
